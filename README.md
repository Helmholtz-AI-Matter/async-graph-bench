# Async Graph Bench

Asynchronous Benchmarking of Large Language Models and other Models

## What is this?

This python module provides a benchmarking framework that allows for cached multi-stage graph based benchmarking. It was designed for benchmarking LLMs, but can also be used with other models.

## Installation

Install locally using `pip install -e .`

## Examples

You can find examples for different benchmarking applications in `examples/`.

## Documentation

The documentation is mainted in `docs/`. These are sphinx-generated pages. We are currently working to host as webpages.
